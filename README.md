# agentic-ai

A repo for agentic ai workflows.

## Pre-Requisites

- `uv`

## Setup

1. Create a Python environment:
    ```bash
    uv venv
    ```

2. Activate the environment:
    ```bash
    uv venv
    ```
    *Windows*
    ```bash
    .\.venv\Scripts\activate
    ```
    *Linux/Mac*
    ```bash
    source .venv/bin/activate
    ```

3. Install dependencies:
    ```bash
    uv sync
    ```
